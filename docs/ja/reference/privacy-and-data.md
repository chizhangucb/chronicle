# プライバシーとデータ

Chronicle が何を保存し、どこに保存し、そしてマシンの外に出る数少ないものの完全なリストを示します。

Chronicle は設定によってではなく、設計としてローカルファーストです。パース、保存、閲覧、リプレイ、さらには共有リンクの生成まで、すべてがデバイス上で行われ、オプトアウトすべきクラウドバックエンドは存在しません。このページは正直な会計報告です。すなわち、その保証、外部への正確なネットワーク通信（3 つだけで、いずれもユーザーが起点となるか任意のものです）、そしてデータが物理的にどこに存在するかを示します。

## ローカルファーストの保証

- **すべての処理はデバイス上で行われます。** インポート、パース、保存、検索、タイムトラベル、因果関係分析、秘匿化（redaction）、リプレイ、そして共有ページの構築は、すべてお使いのマシン上で完結します。
- **LLM 呼び出しはどこにもありません。** AI のように見えるものすべて — 因果関係の信頼度ティア、シークレットの秘匿化、コスト計算 — はローカルのヒューリスティックか静的なテーブルです。Chronicle があなたの会話をモデルに送信することは決してありません。
- **クラウドバックエンドもアカウントもありません。** サインインするものは何もなく、あなたのデータを保持するサーバーも存在しません。
- **元のログに書き込むことはありません。** Chronicle はツールのログを読み取るだけで、変更も削除もしません。SQLite ベースのソース（Cursor、OpenCode）は、`-wal`/`-shm` のサイドカーファイルを含めて一時領域へコピーされ、Chronicle が開くのはその*コピー*であって、稼働中のデータベースではありません。
- **プロジェクトのリポジトリに書き込むことはありません。** Git スナップショットエンジンは厳密に読み取り専用です。`git rev-list`、`ls-tree`、`show` をシェル実行して、履歴から過去のコード状態を再構築します。コミット、チェックアウト、ステージングは一切行いません。
- **外部システムに対しては読み取り専用。** この読み取り専用の姿勢は、すべてのツールのデータに適用されます。Chronicle は常に観測するだけです。

## マシンの外に出るもの

デフォルトでは、Chronicle はセッションの閲覧や管理のためにネットワーク通信を**一切**行いません。外部への通信は 2 つだけ存在し、いずれも任意か、あなたが明示的にトリガーするものです。

1. **アップデートの確認とダウンロード。** パッケージ版のデスクトップアプリでは、`electron-updater` が公開の `chizhangucb/homebrew-chronicle` タップの GitHub リリースフィードをポーリングし、新しい公証済みビルドをバックグラウンドでダウンロードします。これは標準的なアプリ更新の経路で、セッションデータは一切含まれません。
2. **フィードバック（送信したときのみ）。** フィードバックフォームを送信すると、`relay.getchronicle.dev` のホスト型リレーに POST します。メッセージは**常に、まずローカルの `~/.chronicle/feedback.log` へ追記される**ため、ネットワークに依存するものはありません。リレーに到達できない場合、UI は `mailto:` の下書きにフォールバックします。送信者メールアドレスの欄は任意です。入力すれば返信先（reply-to）アドレスになり、空欄のままなら、あなたを特定する情報は何もありません。

これ以外にマシンの外へ出るものはありません。特に、パース・閲覧・分析のために**セッションの内容が送信されることは決してありません**。またバックグラウンドの[自動同期](../guide/auto-sync.md)は純粋にローカルのファイル読み取りであり、ネットワーク通信では決してありません。

## 共有リンクはローカルに留まる

共有リンクは、ホスト型サービスではなく、**あなた自身が実行している Chronicle** によって提供されます。共有リンクを作成すると、Chronicle は**作成時点で凍結された、秘匿化済みのトランスクリプトのコピー**を保存し、ローカルの `/share/:token` ページから提供します。元のセッションがアップロードされることはなく、作成後の編集が既存の共有に影響することもありません。閲覧数の確認とリンクの即時失効は、共有管理（Share Management）から行えます。

## データの保存場所

Chronicle が永続化するものはすべて `~/.chronicle/` 以下にあります（全体の構成は[設定](./configuration.md)を参照）。`~/.chronicle/chronicle.db` の SQLite データベース、リプレイサンドボックス、`feedback.log` です。すべてあなたのディスク上に留まります。

> **秘匿化は一方向です。** Chronicle がシークレットを秘匿化するとき — 共有リンク、エクスポートされた Markdown トランスクリプト、セキュリティスキャンのいずれであっても — 機微なテキストは置き換えられ、可逆的なマッピングは保持されません。秘匿化された成果物を元に戻すことはできず、その過程で保存されている原本が変更されることもありません。
